（需要时）跑 `pnpm test` / `pnpm replay:corpus` / `pnpm fuzz` 全量复核。

## 引用粒度政策（诚实声明）

- 章节号引用以**仓内既有引用**为准：源码注释、IR 类型注释与测试标题中已逐条核对的
  WMO 306 §15.x、FMH-1 12.x、AP-117 条款号、ICAO Annex 3 附录号与电码表编号。
- 无法落实到具体章节号的条款，出处标注为「FM15 代码形 + 电码表 XXXX」级描述——
  不做超出证据的章节号声明。
- 「回归锁」列为锁定该条款行为的测试（describe/it 名，节选可辨识片段）与机制
  （语料回放 / fuzz 不变量）。测试名以仓库当前版本为准，`grep` 测试名即可定位。
- FMH-1 与 MANOPS 的最新版原文未完全公开可取，相关条款以可获得的官方文本引证并用
  真实语料互证（与根 README 诚实声明一致）。
