# 语料回放基线（corpus）

本目录是解析器的**全球静态样本语料 + 回放快照**——防「形态盲区」复发的机制数据面：
任何让新 unknown 形态静默出现的解析器改动，都会被 `packages/parser/src/corpus.test.ts`
的快照断言拦下（测试红，逼着提交者显式处理新形态或更新快照）。

> **数字口径**：表内条数与下文的体量数字是采集时次（2026-09-12）的信息性快照值，随样本刷新而变——
> 权威数字以 `snapshot.json` 的 `files/*.lines` 与 `total` 字段为准（`corpus.test.ts` 锁两者与文件一致，
> 本文件不再单独维护数字）。

tgftp 单个 cycle 原始约 9,500 条唯一报文（~2.2MB 量级，09Z 实测 9,586——以生成脚本实测为准），入库做了**分层抽样**：

1. **特殊形态全保留**：NIL、跑道状态/RVR 组、SNINCR、LTG、变化能见度 `VIS xVy`、
   冰积组 `I1nnn`、began/ended 合并形态、`/////KT`/`////`/云组 `///` 缺测、5 位 QNH、
   `M…SM`/`P…SM` 阈值能见度、VV 组、COR、RE 近期天气（约 620 条）；
2. **CAVOK 封顶 150 条**（全球报文中太常见，按文件序取前 150）；
3. **其余等距填充**至总量 ~2000（每 ⌈剩余/所需⌉ 条取一，保持原文序的地区分布）；
4. **排除项**：17 条含北欧跑道冬季状态码（`W##/S#`、`W##/H#` 家族）的报文被移出样本——
   该形态与仓库公开面文本门禁存在保守冲突。这些报文在解析器下的行为与其他未知组一致
   （进 `unknown-token` 告警，不丢弃）；本切片中该家族曾因泄露扫描的周编号模式误伤被移出（17 条）；2026-09-12 按 owner 裁决收紧模式为年份锚定（\\b[12]\\d{3}-W\\d{2}\\b）后已回填本 cycle 全部去重样本（22 条），北欧冬季形态纳入快照锁。

抽样对同一切片文件是确定性的（无随机数）；tgftp 每小时覆盖同名文件，刷新样本会得到新切片。

## 使用

```bash
# 回放并看摘要（需先 pnpm build 出 parser dist）
node scripts/replay-corpus.mjs corpus/*.txt

# 对比模式：列出相对快照新增的 unknown 形态（CI/钩子可用，新增即退出码 1）
node scripts/replay-corpus.mjs corpus/*.txt --baseline corpus/snapshot.json

# 重生成快照（解析器行为有意的变更后）
node scripts/replay-corpus.mjs corpus/*.txt --json corpus/snapshot.json
```

**快照纪律**：更新 `snapshot.json` 必须在 commit message 中说明原因（新形态已处理 /
样本切片刷新）。`pnpm test` 里的冒烟锁（`packages/parser/src/corpus.test.ts`）断言
unknown 形态分布与快照完全一致。

## 数据许可定位

样本均为**公开通路分发的机场观测报文原文**（NWS tgftp 与 IEM 公益聚合器），
用于本仓库的解析器测试；属事实性观测数据，入库旨在保证测试的可复现性。
商用前请自行核实数据提供方的分发条款（详见根 README 风险披露）。
